# GitBook-Style Collaborative Docs

A self-hostable documentation and knowledge-management platform combining a GitBook-style reading experience with Confluence-style collaboration.

## Project status

The product design is approved and ready to be translated into an implementation plan. No application code has been scaffolded yet.

## Design

Read the [product and architecture specification](docs/superpowers/specs/2026-10-10-gitbook-style-collaborative-docs-design.md) before starting implementation.

The first release targets public product documentation and private company knowledge bases, with browser editing, Markdown/Git synchronization, roles, comments, reviews, page history, search, and controlled publishing.
